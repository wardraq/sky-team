| pdf-pages/ | 每页 PNG（2× 渲染，供核对） |
| DESIGN.md | 本项目设计与实现 |

## 重新生成页图

```bash
pip3 install pymupdf
python3 - <<'PY'
import fitz, os
pdf = 'docs/SkyTeam.pdf'
out = 'docs/pdf-pages'
os.makedirs(out, exist_ok=True)
doc = fitz.open(pdf)
for i in range(doc.page_count):
    doc[i].get_pixmap(matrix=fitz.Matrix(2, 2)).save(f'{out}/page-{i+1:02d}.png')
print(doc.page_count, 'pages')
PY
```

## 与代码实现的差异

| 项目 | PDF / 文档 | `game-logic.js` |
|------|------------|-----------------|
| 起落架 | 3 槽（1/2、3/4、5/6） | 3 槽（gear1–gear3） |
| 集中精力 | 共用 ☕ 槽 ×3 | coffee1–coffee3（shared） |
| 蓝标记起始 | 4 与 5 之间 | `BLUE_START: 5` |
