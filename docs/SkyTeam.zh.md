## 游戏简介

**Sky Team（天合小队）** 是一款 **2 人合作** 桌游（14+，约 20 分钟）。你们共同操控民航客机，在进近着陆的全过程中协作：

- 与 **塔台** 通信，清空航路
- **调整速度**，避免冲出跑道
- 保持 **水平姿态**
- 放下 **襟翼** 与 **起落架**
- 接地后 **刹车** 减速

合作与冷静是成功的关键。视频规则：[scorpionmasque.com](https://scorpionmasque.com)

## 首次开箱

1. 移除并丢弃控制面板上所有带 **垃圾桶** 标记的 punch-out 部件。
2. 将 **9 张双面贴纸** 贴到控制面板 **内层** 与 **背面** 指定位置（作脚垫）。
3. 飞机贴纸贴到 **姿态圆盘（Airplane Axis disc）**，装入中央槽位。
4. 将 **10 个拨杆** 盖住绿灯：**起落架 3 + 襟翼 4 + 刹车 3**。

### 控制面板区域

| 区域 | 说明 |
|------|------|
| Reroll | 重掷标记供应区（左上） |
| Radio | 无线电（左上 1 + 右上 1） |
| Current Position screen | 当前位置窗（进近轨） |
| Current Altitude screen | 当前高度窗（高度轨） |
| Axis | 姿态（中央圆盘） |
| Landing Gear | 起落架，机长侧，**3 槽** |
| Flaps | 襟翼，副驾侧，**4 槽** |
| Engines | 引擎（姿态下方，双色） |
| Brakes | 刹车（底中，**3 槽**） |
| Concentration | 集中精力 / 咖啡（最底） |

## 游戏流程

共 **7 轮**。每轮 **3 阶段**：

### 阶段 1 — 策略讨论与掷骰

- 可讨论策略（如「得清掉那架飞机」「这轮前进 2 格」）。
- **禁止讨论骰子点数**（如「你要是 6 就放这儿」）。
- 各人在挡板后掷 **4 颗骰**；此后至本轮结束 **保持沉默**（纠正规则错误除外）。

**重掷：** 若当前高度窗格上有重掷标记（如第 1 轮 6000 英尺），移入面板左上供应区。轮内任一人可消耗 1 枚，**双方** 各自可在挡板后 **重掷任意颗** 自己骰子 **各一次**。

### 阶段 2 — 放置骰子

轮流每次 **恰好 1 颗**，直至 8 颗全部就位。先手由 **当前高度** 窗箭头指示（第 1 轮机长/蓝先）。

| 规则 | 内容 |
|------|------|
| 颜色 | 机长 → 蓝槽；副驾 → 橙槽 |
| 双色槽 | **姿态、引擎** 及底部 **3 个 ☕ 放骰槽** — 任一方可放 |
| 点数 | 许多槽位有骰值限制（如襟翼首档仅 1/2） |
| 无线电 | 仅颜色限制，任意点数 |
| 集中精力（☕） | **3 个**双色槽，无限制，任意玩家任意点数 |

### 阶段 3 — 轮末结算

8 颗放完后可再次交谈，然后 **按序**：

1. **降低高度** — 高度轨前进 1 格（−1000 英尺）；共 7 格 = 7 轮。
2. **收回骰子**。
3. 若 **当前位置** 显示 **机场** 且 **当前高度** 显示 **飞机图标** → 进入 **终局/着陆轮**（见下）；否则开始新一轮。

## 行动说明

骰子效果取决于 **放置位置** 与 **点数**。  
**姿态、引擎**：第二颗骰放上该槽时 **立即结算**。  
**无线电、起落架、襟翼、刹车、咖啡**：放置当下 **立即生效**（多数情况）。

### 强制行动 ⚠

每轮每人必须在 **姿态** 与 **引擎** 各放 **1 颗**（不必优先放置）。

> 轮末若姿态或引擎缺少 **任一颜色** 的骰子 → **立即判负**。

---

### 姿态 Axis ⚠

管理滚转；避免尾旋。

**第二颗姿态骰放上时** 比较两点数：

| 结果 | 效果 |
|------|------|
| 相同 | 不变 |
| 不同 | 圆盘转 **差值** 格，箭头指向 **大点** 一方；**轮末不复位** |
| 箭头到达/越过 X | **尾旋，立即判负** |

> 真实飞机有偏航、俯仰、滚转；本游戏仅模拟 **滚转**。

**胜利条件 C：** 最后一轮结束时姿态 **完全水平**。

---

### 引擎 Engines ⚠

**第二颗引擎骰放上时**，两点数相加 = **速度**，对照速度表两枚气动标记：

| 引擎和 | 进近轨 |
|--------|--------|
| **<** 蓝色（较低）标记 | **不移动**（0 格） |
| **≥ 蓝 且 ≤ 橙** | 前进 **1** 格 |
| **>** 橙色（较高）标记 | 前进 **2** 格 |

示例（蓝标记在 5、橙在 8）：和 **4**→0 格，**7**→1 格，**10**→2 格。

进近轨 **整卡下滑**；Current Position 为面板 **固定窗口**。

**碰撞：** 前进后 token **刚移入** 当前位置 → 存活；**已在** 当前位置且 **必须** 前进 → **碰撞，判负**。

**冲出：** 机场已在当前位置仍须前进 → **冲出，判负**。

---

### 无线电 Radio

联系塔台，清除进近路径上的飞机。

- 机长 **1** 槽 · 副驾 **2** 槽 · 任意点数。
- 从 **当前位置** 起沿进近方向数 N 格；**立即移除** 该格 1 架飞机。
  - **1** = 当前位置；**2** = 再往前 1 格，依此类推。
- 该格无飞机 → 无效果。

**胜利条件 A：** 进近轨上无飞机 token。

---

### 起落架 Landing Gear（仅机长）

增加阻力。**3 槽**，点数 **1/2 · 3/4 · 5/6**，**顺序不限**。

- 放置符合限制的骰 → 拨杆绿灯 → **立即** 蓝气动标记 **+1**。
- 3 档全放出 → 蓝标记在 **7 与 8 之间**。
- 已在绿灯位再放 → **无效果**（可浪费骰）。

**胜利条件 B（部分）：** 3 个起落架拨杆均为绿灯。

---

### 襟翼 Flaps（仅副驾）

增加升力与阻力。**4 槽**，**须按序**：**1/2 → 2/3 → 4/5 → 5/6**。

- 放置 → 拨杆绿灯 → **立即** 橙气动标记 **+1**。
- 全放出 → 橙标记刚过 **12**。

**胜利条件 B（部分）：** 4 个襟翼拨杆均为绿灯。

---

### 气动与速度

移动蓝/橙标记会改变引擎和对的含义。例：蓝标记前移后，速度 **5** 可能从前进 1 格变为 **0** 格。

---

### 集中精力 & 咖啡 ☕

| 类型 | 数量 | 作用 |
|------|------|------|
| ☕ **放骰槽** | **3**（底部蓝橙双色、带咖啡杯图标，p.4 规则 F） | 在空闲槽放 1 骰 → 得 1 枚咖啡 |
| **token 存放位** | **3**（p.8 designated spaces） | 立即将 token 放入其一；板上 **最多 3 枚** |

**使用咖啡：** 放置 **任意** 骰子的 **那一刻**，可消耗 **1 枚或多枚** token，对该骰 **±1**（每枚 ±1；结果保持 1–6；**1 不能变 6，6 不能变 1**）。任一方可用；未用完留至下轮。

---

### 刹车 Brakes（仅机长）

接地后减速。**须按序 2 → 4 → 6**；放置 → **立即** 红标记在 **2–6 刻度轨** 上右移一格。

- 不必全部部署；部署越多着陆越容易。
- **仅着陆轮** 用刹车与速度比较（见下）。

**胜利条件 D：** 着陆轮引擎和 **<** 红刹车标记位置。

---

## 特殊情况

### 过早到达机场（等待航线）

- **当前位置** 已是机场，**当前高度** 尚未显示飞机。
- 须完整进行一轮或多轮；**进近轨不得再前进**；速度须 **0 前进**（引擎和 **<** 蓝标记）。

### 未能及时到达

- 高度已显示飞机，位置 **不是** 机场 → **未进场坠毁，判负**。

---

## 着陆轮与终局

当 **机场** 与 **飞机** 图标 **同时** 出现在各自窗口时（通常在 **轮末降高度并收骰之后** 判定），进入 **着陆轮**。

> 你正好在飞机触地的同时到达机场。

### 着陆轮的引擎

**第二颗引擎骰放上时**，速度 **不再** 与气动标记比较，改为与 **刹车** 比较：

- 引擎和 **<** 红刹车标记 → 满足条件 D。
- 不必填满所有刹车，但红标记 **不能停在 2 以左**（至少须部署过刹车 2）。

---

## 胜利条件（着陆轮结束时）

**须全部满足：**

| | 条件 |
|---|------|
| **A** | 进近轨上无飞机 token |
| **B** | 起落架 **3** + 襟翼 **4** 拨杆均为绿灯 |
| **C** | 姿态圆盘完全水平 |
| **D** | 放置引擎骰时，速度 **<** 刹车值 |

成功后可打开 **Flight Log（飞行日志）** 挑战进阶场景。

## 策略提示（可选）

> 除非屡次着陆失败，否则不建议阅读。

- **简报：** 每轮初审视进近轨 — 前进 0/1/2？什么最急？
- **沟通：** 掷骰前口头交流；放置阶段用骰子选择传信。
- **姿态：** 两人都拖到最后一骰很危险；末轮之前较灵活。
- **咖啡：** 浪费一颗骰 = 少一次行动；适时为搭档留 token。
- **速度：** 前方有飞机时要尽早传递引擎强度。
- **襟翼/起落架：** 需前进 2 格时勿过早放襟翼；想悬停可放低起落架（抬蓝标记）。
- **无线电：** 优先清 1–2 格；不要用第一颗骰把飞机推远。

## 进近轨效果

### 交通骰 Traffic

轮初 **当前位置** 有 Traffic 图标时，按图标数量掷交通骰，从当前位置起数格 **添加飞机**。

- 无图标 → 不掷。
- 同一 Traffic 格停留多轮 → 每轮初再掷。
- 前进 2 格 **经过** Traffic 格 → 不触发。
- token 用尽 → 跳过；点数超出轨道 → 放在最后一格（机场）。

### 转弯 Turns

前进进近轨时，姿态须在 **当前位置** 窗口允许的 ▼/▽ 范围内；前进 **2 格** 则 **两格均须满足**；前进 **0** 不检查。（具体约束印在进近轨上，如 HND。）

## 进阶模块

### 燃油 Kerosene

- 燃油轨置面板左侧；标记从 **20** 起。
- 机长或副驾放任意骰 → 标记下移等于点数。
- **轮末** 未在燃油槽放骰 → **失去 6** 单位。
- 标记到 **X** → **立即判负**。

### 实习生 Intern

- 实习生板置于面板下方；每格随机 token。
- 轮到你时，在你颜色格放骰 → 取最近 token → 当骰子放到合法槽位，按 token 点数结算。
- 着陆时板上仍有 token → **判负**。
- token 不能被咖啡修正；不能用于集中精力；培训骰点数须与下一 token **不同**。

### 风 Wind

- 风向环置面板右侧；蓝飞机 token 机头指向白色中心（0）。
- **姿态阶段后：** 按当前姿态偏移旋转 token（即使本轮姿态未动）。
- **引擎阶段：** 引擎和 **加上** 风向值（**−3 … +3**），**含着陆轮**。

### 实时 Real-Time

- 每轮掷骰后 **立即** 启动 **60 秒** 计时。
- 时间到 → 本轮结束；未放置的骰忽略；姿态/引擎未填满 → **判负**。

### 燃油泄漏 Kerosene Leak

- 燃油轨照常；燃油骰槽用 token 盖住（不可主动加油）。
- 轮末耗油 = **|引擎骰₁ − 引擎骰₂| + 1**。

### 冰面刹车 Ice Brakes

- 冰面刹车板覆盖原刹车区；**无拨杆**。
- **同一轮** 上下配对格放 **两颗同点数** 骰 → 标记前移；只放一颗 → 该骰收回，标记不动。
- 从左到右按序（**2→3→4→5** 四列）；一轮可多次前移。
- 游戏结束前标记须到 **5 以右**，否则 **判负**；着陆轮仍要求速度 **<** 标记。
