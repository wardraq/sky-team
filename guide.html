天合小队 · 怎么玩

这是一份可随时查阅的新手指导：先读「5 分钟上手」和「每轮流程」，开玩后把本页留在第二个标签页， 用界面地图对照屏幕上的每个区域。比弹窗规则更适合边玩边查。

👥 双人联机 🎲 掷骰后禁谈点数 🛬 7 轮内降落 📱 机长 / 副驾各开一页

5 分钟上手

  1. 运行 node server.js，浏览器打开 大厅。
  2. 输入相同房间号，选择同一关卡。
  3. 两人分别点机长（蓝）与副驾（橙），各开一个标签页。
  4. 都进入后自动开局。每轮：讨论 → 秘密掷骰 → 轮流放骰 → 确认结算。
  5. 第 7 轮（或提前到达机场进入着陆轮）满足全部条件即胜利。
核心技巧：掷骰后不能告诉对方「我掷了几点」，只能通过放哪个槽位、什么顺序来传递信息。讨论阶段可以商量策略，但不能说具体点数。

每轮流程

1

策略讨论 discuss

公开商量「这轮要不要清飞机」「谁放引擎」等，禁止提骰子点数。准备好后点「开始掷骰」。

2

秘密掷骰 roll

各自点「掷骰」，4 颗骰子只有你自己能看到。对方界面显示 🔒。双方都掷完后进入放置。

3

轮流放置 place

机长 / 副驾交替操作：点一颗骰 →（可选）用 ☕ 修正 → 点空槽位。姿态、引擎第二颗放上会立即结算。8 颗放满进入揭示。

4

揭示结算 reveal

确认本轮结果：降低高度、检查终局条件。可在此阶段用剩余 ☕ 微调已放置的骰（若规则允许）。

轮内任意时刻可消耗 🔄 重掷标记：双方各自点选要重掷的骰子，各重掷一次（放置阶段仅限未用骰）。

① 联机大厅

大厅

进入游戏前

#lobby-screen · 首次打开页面

  • 房间号：两人必须一致，例如 sky。
  • 关卡：下拉选择场景；机长选关后副驾会同步。
  • 角色卡片：机长 / 副驾 / 乘客（观战只读）。

② 顶栏状态

顶栏

全局快照

header.topbar · 游戏中顶部

  • ◀ 离开房间回到大厅。
  • 轮次 当前第几轮 / 共 7 轮。
  • 高度 当前高度（英尺）；与高度轨同步。
  • 距机场 航道上的距离格，0 = 到达机场。
  • 姿态 水平仪读数，0 为水平，±3 尾旋坠毁。
  • 刹车值 着陆轮速度上限，随刹车槽激活增加。
  • ☕ 剩余咖啡 token，放置时可修正骰点。
  • 🔄 剩余重掷标记数量。
  • 📖 规则 打开简短规则弹窗（本页更详细）。

③ 左右面板

A

骰子区

panel-pilot / panel-copilot 顶部

你的 4 颗骰子。放置阶段轮到你时高亮；已用的骰变灰。对方掷骰阶段你只能看到自己的点数。

  • 掷骰：roll 阶段点击，结果仅自己可见。
  • ☕ 修正预览条：选中骰子后出现 +1 / −1 / 清除，与剩余 token 联动。
  • 黄色提示条会说明当前该做什么（轮到你了 / 等待对方等）。
B

姿态 · 引擎 · 无线电

姿态 / 引擎：双方各 1 槽，强制每轮必须各放 1 颗。第二颗放上时立即比较并倾斜 / 推进。

无线电：机长 1 槽；副驾「·左」「·右」2 槽。骰点 N = 从当前位置数第 N 格，清除该格飞机（1=当前格，2=前方第一格…）。

C

起落架（机长）

左侧面板

3 个槽：限 1/2、3/4、5/6，顺序任意。激活后蓝速度标记前移，终局须全部激活。

D

襟翼（副驾）

右侧面板

4 个槽须按 1/2 → 2/3 → 4/5 → 5/6 顺序激活。每激活一档橙速度标记前移。

④ 中央仪表

1

阶段横幅

显示当前阶段与操作说明；右侧按钮随阶段变化（开始掷骰 / 完成放置 / 确认结算 / 重掷确认等）。

2

航道

距离 6 → 0 的进近格。✈️ = 你的位置；🛩 = 交通飞机。警告条会提示撞机风险与无线电所需骰点。

3

高度轨

每轮结算下降一格。边框颜色表示该高度谁先手（蓝=机长，橙=副驾）。🔄 格轮初收入重掷标记；着陆高度格显示 🛬。

4

姿态仪

人工水平仪：双方姿态骰比较后倾斜。放置阶段会显示预览。终局必须完全水平 (0)。

5

引擎 / 速度

双骰之和对比蓝、橙标记：低于蓝悬停；蓝~橙前进 1；高于橙前进 2。放置阶段显示预览与撞机警告。

6

刹车 & 集中精力

刹车：机长 2→4→6 顺序激活，刻度轨 0（2 左侧）→ 2 → 4 → 6；每激活一档标记 +2。☕：共用 3 个放骰槽，获得 token；放任意骰时可消耗修正 ±1。

7

日志 & 终局

飞行日志：记录每轮关键事件（姿态、引擎、无线电、失败原因等）。终局卡片显示胜利 / 失败与统计。

槽位速查

数字表示该角色有几个放骰槽；「强制」= 每轮必须各放 1 颗。侧栏槽在左右面板，标「中央」的在中间仪表区。

协作与 FAQ

为什么对方看不到我的骰子？
联机版由服务端过滤状态，roll 阶段隐藏对方点数——这是 Sky Team 的核心机制，不是 bug。
无线电放了为什么飞机还在？
清除哪一格由骰点决定，不是槽位名。例如在前方 1 格有飞机时，需要骰点 2（1=当前格）。
经过有飞机的格子会撞吗？
官方规则：仅当当前位置有飞机且你必须前进时才撞机；单纯经过前方格可以存活。
本地怎么双人测试？
同一浏览器开两个标签，分别进机长和副驾，房间号与关卡保持一致。
想看更完整规则？
游戏内 📖 规则弹窗，或仓库内 docs/DESIGN.md、docs/SkyTeam.zh.md。
